  - **Final vertical alignment mechanism is a runtime JS measurement, not a hardcoded pixel value.** The user's exact spec was: bottom-right corner of the main image must align horizontally with the bottom-left corner of the 2nd-row-left option card (Gold Single, the 3rd `.cv-offer-card-{{ sid }}`), while explicitly forbidding both guessed pixel values and asking the user for one. **Core architecture pattern established (reuse this for any future per-template-only override):** `layout/theme.liquid` computes a palette/variant choice keyed off `template.suffix` (e.g. `if template.suffix == 'pdrn-sandbox'`) and passes it as a parameter into a shared snippet/section, which defaults to production behavior otherwise. This is how the color-token system (`snippets/elsora-design-tokens.liquid`, param `active_palette`, active palette for this template is `ice-globes`) and the cart icon swap are scoped to the sandbox page only. Don't hardcode a global override for a per-page need — always route it through `template.suffix`.
